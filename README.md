# Vasquez Towing

One-page website for Vasquez Towing, Darwin Vasquez's flatbed towing service
in Northern Virginia. Call or text 571-568-1530.

## Structure

- `index.html` — the whole site (styles and script are inline)
- `img/` — truck photos

No build step. Open `index.html` in a browser, or serve the folder with
`python3 -m http.server 8000`.

## Hosting

Published with GitHub Pages from the `main` branch, root folder.
